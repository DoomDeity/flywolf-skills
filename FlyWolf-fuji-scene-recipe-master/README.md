# 富士现场配方师 / Fujifilm Scene Recipe Master

版本：3.0.0

根据用户上传的手机或相机现场图，分析光线、反差、色温、主体、环境色和目标风格，生成 3 套可以直接试拍的 Fujifilm JPEG 直出色彩配方。用户说明不满意原因后，会基于同一张现场图重新生成 3 套有明确变化的新方案。

## 3.0 更新

- 首轮固定给出 3 套完整方案：安全还原、氛围平衡、风格强化；
- 每套都包含完整参数表、一句话抄机版、适用取向和风险；
- 支持“太黄、太灰、太硬、不够复古、想更清透”等具体反馈；
- 反馈轮不原样重复上一轮，而是解释变化后重新输出 3 套完整配方；
- 保留机型兼容、动态范围与最低 ISO 联动、彩色/黑白模板和置信度说明；
- 增加 minitool/ 离线 H5 源码，可按小红书小工具规范打包。

## 使用方式

将整个 FlyWolf-fuji-scene-recipe-master 文件夹复制到支持 Skill 的 Agent 技能目录，然后上传一张现场图。

首轮可以直接说：

~~~text
根据这张现场图给我 3 套富士直出参数。
~~~

带更多信息的例子：

~~~text
这是手机拍的现场图，我用富士 X100VI，想要低饱和电影感。请给我 3 套完整参数，并告诉我先试哪一套。
~~~

反馈轮例子：

~~~text
三套都太黄、太艳了，肤色不自然。我想保留现场暖光，但更干净、更像胶片，请重新给我 3 套。
~~~

## 输出内容

1. 现场判断：光线、反差、色温/环境色、主要风险和判断置信度；
2. 三套完整配方：每套独立参数表，不用“同上”省略；
3. 方案差异：每套的风格取向、取舍和机型兼容提醒；
4. 先试建议：推荐一个起始方案；
5. 试拍微调：只给最相关的曝光、色偏和暗部调整；
6. 反馈入口：说明用户可以告诉技能具体不满意的原因，进入下一轮。

配方是基于单张图的现场试拍起点，不保证百分之百复刻真实胶片或参考图。截图、滤镜、HDR、平台压缩、手机屏幕和现场光变化都会影响结果。

## 目录结构

~~~text
FlyWolf-fuji-scene-recipe-master/
├── SKILL.md
├── README.md
├── agents/
│   └── openai.yaml
└── minitool/
    ├── index.html
    └── assets/
        ├── app.js
        └── style.css
~~~

SKILL.md 是 Agent 使用的判断逻辑和输出契约。minitool/ 是纯本地 H5 实现：照片在设备内进行像素级光线估计，不联网、不上传图片；它适合直接打包成小红书小工具，不能把本地启发式估计描述成云端 AI 识别。
